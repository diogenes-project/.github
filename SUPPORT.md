# Support

## Getting help

- **Bugs and feature requests** — open an issue in the
  [diogenes](https://github.com/diogenes-project/diogenes) repository
  using the issue template.
- **Questions and general discussion** — use
  [GitHub Discussions](https://github.com/diogenes-project/diogenes/discussions)
  on the diogenes repository.
- **Documentation** — see the
  [Diogenes README](https://github.com/diogenes-project/diogenes#readme)
  for usage, installation, and configuration.

## Expectations

Diogenes is a community project maintained by volunteers. There is no
SLA-backed support. Issues and discussions are addressed as time
permits. We appreciate your patience.
